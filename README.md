# Sales Analysis Dashboard – Power BI

## Project Overview
This project focuses on designing an interactive Sales Analysis Dashboard using Microsoft Power BI. The dashboard helps analyze sales performance, profit, product sales, order quantity, and regional performance through charts and KPI cards.

## Objectives
- Analyze total sales and profit.
- Track the total number of orders and products.
- Understand sales performance across different categories.
- Identify the top 5 products based on sales.
- Compare sales and profit across regions.
- Analyze monthly sales and profit trends.
- Create an interactive dashboard for easy data exploration.

## Tools Used
- Microsoft Power BI Desktop
- Excel
- DAX (Data Analysis Expressions)

## Dataset Description
The dashboard uses a sales dataset containing the following columns:

- `Category`
- `Discount`
- `Order_Date`
- `Order_ID`
- `Product`
- `Profit`
- `Quantity`
- `Region`
- `Sales`
- `Unit_Price`

## Key Performance Indicators (KPIs)
The dashboard includes the following KPI cards:

1. **Total Orders:** Counts unique order IDs.
2. **Total Products:** Counts unique product names.
3. **Total Quantity:** Calculates the total quantity sold.
4. **Total Sales:** Calculates the total sales value.
5. **Total Profit:** Calculates the total profit.

## Dashboard Visualizations
The dashboard contains the following visualizations:

- **Sales by Month:** Shows monthly sales trends.
- **Sales by Category:** Compares sales across product categories.
- **Top 5 Products by Sales:** Identifies the five products with the highest sales.
- **Sales by Region:** Compares sales across regions.
- **Sales vs Profit by Region:** Compares sales and profit across different regions.
- **Profit by Month:** Displays monthly profit trends.
- **Sales by Category Share:** Shows the contribution of each category to total sales.

## Dashboard Features
- KPI cards for quick performance tracking.
- Bar charts, column charts, line charts, and a doughnut chart.
- Visual comparison of sales and profit.
- Date, category, region, and product filters, where configured.
- Consistent formatting and a user-friendly layout.

## Key Learnings
- Importing and working with sales data in Power BI.
- Creating measures using DAX.
- Designing KPI cards and charts.
- Applying filters and slicers.
- Formatting visuals and arranging dashboard elements.
- Analyzing sales and profit performance.
